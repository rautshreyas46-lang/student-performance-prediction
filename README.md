# Student Performance Prediction

## Project Overview

This project predicts a student's exam score based on academic, personal, and family-related factors using Machine Learning.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib
- Jupyter Notebook

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Missing Value Handling
4. Categorical Feature Encoding
5. Feature Preparation
6. Train-Test Split
7. Machine Learning Model Training
8. Model Evaluation
9. Student Exam Score Prediction
10. Streamlit Application

## Dataset

The dataset contains student-related information such as:

- Hours Studied
- Attendance
- Sleep Hours
- Previous Scores
- Tutoring Sessions
- Physical Activity
- Parental Involvement
- Access to Resources
- Motivation Level
- Family Income
- Teacher Quality
- School Type
- Peer Influence
- Parental Education Level
- Distance from Home
- Gender

## Model Evaluation

The model was evaluated using:

- MAE
- MSE
- RMSE
- R² Score

## Streamlit Application

The project includes a Streamlit application where users can enter student details and receive a predicted exam score.

## Project Files

- `app.py` – Streamlit application
- `Untitled.ipynb` – Data analysis and model development
- `StudentPerformanceFactors.csv` – Dataset
- `StudentPerformanceFactors.csv.pkl` – Trained model
- `StudentPerformanceFactors.csv_encoder.pkl` – Categorical feature encoder
- `StudentPerformanceFactors.csv_info.pkl` – Feature information
